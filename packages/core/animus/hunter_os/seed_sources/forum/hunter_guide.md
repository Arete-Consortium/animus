## COMBAT HEALER — HUNTING HORN + LBG
**Status:** VERIFIED  
**Core support:** Wide-Range / Speed Eating / Free Meal  
**HH function:** Horn Maestro, then weapon-relevant offense and uptime  
**Secondary:** LBG for ranged utility; ammo availability is gun-specific, so do not assume every LBG supports every ammo type  
**Swap layer:** Element resistance or status counter based on the selected monster  
**Rule:** Heal meaningful damage/status; preserve combat uptime.

**Pairing**
- **Hunting Horn:** Primary frontline support: buffs, KO/head pressure, songs and wound punish
- **LBG:** Secondary utility/range option; ammo table determines actual role
- **Swap trigger:** Use LBG when range, safe status application or gun-specific utility beats staying on HH
- **Avoid:** Swapping merely to "be supportive" when HH pressure/buffs are already providing more value

## PALICO SUPPORT
**Default support**
- Vigorwasp Delivery heals
- Purewasp Delivery clears negative effects
- Song o' Power buffs attack
- Song o' Purrtection buffs defense

**Paracorn:** Places a paralysis trap. It is NOT the hunter's Shock Trap item.  
**Other default tools:** Provoke; Let-'Er-RRRip; support moves can be toggled on/off to shape behavior  
**Unlockable examples:** Attract Vigorwasps; Flashfly Cage; Plunderang; Vigorwasp Revival; Rath-from-Above  
**HH pairing:** Use Palico healing/status support to reduce redundant sheathing and preserve melody/head-pressure uptime.

## ARTIAN FORGE — UNLOCK & PARTS
**Status:** VERIFIED  
**Unlock:** Artian forging opens in High Rank after the first Tempered-monster progression around Chapter 4.  
**Source:** Tempered monsters award appraised Artian weapon parts; higher difficulty yields higher-rarity parts.  
**Melding:** Weapon parts can also be melded later in Suja using endgame melding resources.  
**Rule:** All three forging parts must be the same rarity. Rarity cannot be upgraded later.

## ARTIAN FORGE — FORGING LOGIC
**Element/status:** At least 2 of 3 parts with the same element/status makes the weapon that element/status.  
**Raw:** Using parts without a 2-of-3 element/status match produces a non-elemental/raw result.  
**3-part match:** Three matching elemental/status parts add an additional element/status infusion.  
**Innate infusion:** Part bonuses contribute Attack/Affinity production behavior; always inspect the forge preview before committing.  
**HH warning:** Artian Hunting Horn melodies change with the selected element/status. Preview the melody page in the forge.  
**Bowgun warning:** Artian bowgun ammo behavior can change with the forged attribute; inspect the preview rather than assuming.

## ARTIAN HUNTING HORN — OMILTIKA
**Rarity 8 horn:** Omiltika  
**Required part shapes:** 1 Disc + 2 Devices, all same rarity  
**Song behavior:** Melody set depends on the resulting element/status; raw/non-elemental has a different melody set  
**Combat-healer use:** Paralysis is a strong utility option because its song package can include Divine Protection / ailment utility; elemental variants can offer different offensive/utility melodies  
**Rule:** Choose the SONG PACKAGE and role first, then chase reinforcement perfection.

## ARTIAN REINFORCEMENT
**Levels:** Standard Artian weapons reinforce through five bonus rolls  
**Possible bonuses:** Attack, Affinity, Element/Status, Sharpness; bowguns can also involve ammo-capacity reinforcement  
**Cost:** Rarity 8 reinforcement is expensive; use Smelting Foundry/Festival-share materials efficiently  
**Dismantle:** Dismantling refunds reinforcement materials, but NOT the original Artian weapon parts  
**Practical priority:** Do not blindly chase Affinity. Reinforcement priority depends on weapon, element/status role, sharpness needs and build.

## GOGMA ARTIAN — TU4+
**Upgrade:** Base Rarity 8 Artian weapon + Tarred Device materials from Gogmazios  
**Focus choice:** Attack / Affinity / Element focus changes base stats  
**Skills:** Adds a random Group Skill and Set Bonus Skill  
**Gogma Reinforce:** Can strengthen reinforcement tiers or reset/reroll the reinforcement package  
**Endgame rule:** Do not dismantle a promising R8 base before checking whether it is worth converting into a Gogma Artian.

## ARTIAN FORGE DECISION FLOW
1. Choose exact weapon role: raw / element / status / support
2. For HH: choose desired melody package before reinforcement
3. For LBG/HBG: verify exact ammo table before reinforcement
4. Use same-rarity parts and preview resulting stats/attribute
5. Forge only when the preview matches the intended role
6. Reinforce; keep good rolls, recycle bad weapons for reinforcement materials
7. At late endgame, evaluate Gogma conversion before replacing the weapon
