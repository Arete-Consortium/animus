## INPUT LEGEND
**LB / L1:** Item/ammo/coating selection modifier; correct for ranged selection.  
**RB / R1:** Focus-attack input while Focus Mode is active.  
**LT / L2:** Hold for Focus Mode / aiming.  
**Melee PC:** Focus Mode uses Mouse4/configured key; Focus Strike uses Shift while held.  
**Ranged PC:** Hold RMB to aim/focus; Shift performs the Focus attack.  
**Notation:** + = simultaneous; -> = sequence; contextual actions are labeled.

## HH — ROLE INDEX
**Combat Healer:** Prioritize Health Recovery / Divine Protection / ailment utility, while retaining enough offense to keep pressure.  
**Offensive Support:** Attack Up (L/S), affinity-oriented utility, Evasion/Movement Echo Bubble.  
**Stamina Team:** Stamina Use Reduced + Stamina/Health Recovery Echo Bubble.  
**Element Encounter:** Element resistance song matching the monster plus appropriate elemental horn.  
**Status Utility:** Paralysis/Poison/Sleep/Blast horn where the status and song package both justify the pick.
